# TLDRGraph Workflow Explorer

TLDRGraph creates a source-backed catalog of product and technical capabilities.
Every workflow step links to verified source evidence, and the standalone browser
application lets you inspect those files live.

1. Install TLDRGraph and its agent workflow.
2. Run `tldrgraph init` in your coding-agent session.
3. Complete the source-reading handoff when requested.
4. Run `tldrgraph refresh` after later source changes, then `tldrgraph ui --serve`.

Version 0.3 supports workflow exploration only. Earlier graph-based commands and
generated artifacts are not supported.
